# Product Hunt marketing kit

Ready-to-upload assets for the Country Filter for X Product Hunt page.

## Upload order

1. `01-hero-1270x760.png` — primary gallery image
2. `02-features-1270x760.png` — countries, regions, and exceptions
3. `03-privacy-1270x760.png` — local-only privacy positioning

Use `thumbnail-240x240.png` for the Product Hunt thumbnail. `logo-master.png`
is the full-resolution source logo for any other placements.

The gallery images follow Product Hunt's recommended 1270×760 dimensions, and
the thumbnail follows its recommended 240×240 square dimensions.

These images were created with OpenAI's built-in image generation using the
selected extension logo and existing product screenshots as references, then
normalized to the exact upload sizes.
